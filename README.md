# RepoScout · Android

**Найди код. Разберись в идее.**

[![Android CI](https://github.com/ASimonyan1/reposcout-android/actions/workflows/android.yml/badge.svg)](https://github.com/ASimonyan1/reposcout-android/actions/workflows/android.yml)

Клиент GitHub Search API: поиск открытых репозиториев, страницы результатов и локальные закладки. Учебный проект, подготовленный с помощью AI-инструментов. Дополняет [StudyFlow](https://github.com/ASimonyan1/studyflow-android) сетевым взаимодействием и обработкой асинхронных сценариев.

## Возможности

- Поиск по имени, теме и операторам GitHub (`language:kotlin`, `topic:android`).
- Debounce 500 мс, отмена предыдущего запроса, защита от устаревших ответов.
- Пагинация по 20 записей, устранение дубликатов и предел 1 000 результатов GitHub Search.
- Карточка с описанием, языком, звёздами, форками и переходом в браузер.
- Локальное избранное — не ставит звёзды и не меняет аккаунт GitHub.
- Кеш последних 50 страниц запросов в Room. При сетевой ошибке показываются данные только для совпадающих запроса и страницы, с отметкой времени.
- Ошибки соединения, HTTP 403/429, неверный запрос и повторная попытка.
- Светлая и тёмная темы, загрузка, пустые результаты, частичные результаты API.

## Стек и архитектура

**Kotlin · Compose · Material 3 · Retrofit · OkHttp · Room · Coroutines / Flow · JUnit · MockWebServer**

```text
Compose → ScoutViewModel → ScoutRepository
                              ├── Retrofit → GitHub API
                              └── ScoutStore → Room
```

Поиск: сначала сеть, при ошибке — сохранённая страница. Сбой записи кеша не скрывает успешный сетевой ответ. Отмена корутины никогда не трактуется как повод показать кеш. Избранное наблюдается отдельным Flow из Room.

Каждая новая поисковая строка увеличивает поколение запроса; только актуальное поколение может менять UI. Это защищает даже от источника, который поздно ответил после отмены. При ошибке загрузки следующей страницы ранее загруженные элементы остаются; retry повторяет именно неудачную страницу.

## Запуск

Android Studio, SDK 35, JDK 17/21, Android 8.0+ (API 26). Откройте корень проекта, выполните Gradle Sync и запустите `app`.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Windows: `gradlew.bat`. APK лежит в `app/build/outputs/apk/debug/app-debug.apk` и в **Actions → успешный Android CI → Artifacts → reposcout-debug-apk**.

## Что проверяют тесты

- MockWebServer: кодирование поискового запроса, заголовки, разбор nullable-полей, переход на кеш после HTTP 503.
- Совпадение ключей кеша по запросу и странице; распространение отмены; отказ диска.
- Ограничение пагинации и удаление повторяющихся ID.
- Virtual time: быстрое изменение ввода, запоздалый ответ, очистка строки, повтор неудачной страницы и обновления.

CI не обращается к живому GitHub API в тестах: сеть заменена локальным тестовым сервером.

## Ограничения

Нет OAuth и секретов. Неавторизованный GitHub Search имеет ограничения частоты запросов; приложение показывает ошибку и предлагает повторить позднее. Автоматического обхода лимитов нет. Кеш — сохранённый снимок, может устареть. При изменении результатов между страницами отдельные репозитории могут сдвигаться. Поисковая строка живёт во ViewModel и сохраняется при повороте, но не после уничтожения процесса. Кеш и избранное удаляются при удалении приложения.

Автоматические JVM-тесты проверяют логику и HTTP, но не заменяют проверку Room и UI на устройстве. [План ручной проверки](docs/TESTING.md).
