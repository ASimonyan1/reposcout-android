# Ручная проверка и подготовка к собеседованию

## Сценарии на устройстве

Это план проверки; выполненные автоматические проверки видны в Actions.

1. Ввести `compose language:kotlin`: увидеть результаты и открыть карточку.
2. Быстро менять запрос: после завершения список относится к последнему тексту.
3. Загрузить вторую страницу: предыдущие результаты остаются, повторных ID нет.
4. Сохранить проект, перезапустить приложение, открыть «Избранное».
5. Выполнить поиск онлайн, отключить сеть, обновить тот же запрос: видна отметка кеша.
6. Без сети ввести новый запрос: ошибка, чужие результаты не показываются.
7. Прервать сеть перед следующей страницей: первый список остаётся, retry повторяет нужную страницу.
8. Проверить тёмную тему, большой шрифт, поворот экрана и TalkBack.
